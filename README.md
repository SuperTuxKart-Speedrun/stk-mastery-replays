# Welcome to the Repository!

This repository is designed to help new speedrunners master difficult track shortcuts in **SuperTuxKart**. It provide a centralized, simple, and easy-to-follow collection of **one-lap replays** to accelerate your learning curve.

## Repository Structure

The repository is organized into **branches** representing specific game versions. Each branch contains two common folders:

1. **Addon Tracks**  
   Contains replays for **addon tracks**. These are user-installed tracks that are not included in the default game installation.

2. **Standard Tracks**  
   Contains replays for **standard tracks**. These are the official tracks available immediately upon installing the game.
